サテンブラウス作品検索 v13

API ID不要 / FANZA限定なし
目的は「サンプル画像から、その画像が使われている作品・作品名を探す」ことです。

画像から作品を検索

画像を選択したあとボタンを押すと、同じ画像をGoogle Lensへ直接送信します。Lens側で画像を選び直す必要はありません。

画像を選択してください。

サテンブラウス作品の補助検索

この方式はGoogle Lensの画像アップロード用エンドポイントを利用します。GoogleのChrome実装でも https://lens.google.com/v3/upload が画像アップロード先として使われています。Lensの検索結果には、画像または類似画像を掲載しているWebサイトが含まれます。
